# React Dialogue Editor

A node-based editor designed for game developers to craft narratives. Built with React and React-Flow, this tool provides an interface for mapping out dialogue trees and scene flows.

## 🛠️ Tech Stack

* **Framework**: React
* **Graph Engine**: React-Flow
* **Styling**: CSS Modules
* **Build Tool**: Vite

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/varollo/react-dialogue-editor.git
cd react-dialogue-editor
```

1. Install dependencies

```bash
npm install
```

2. Launch the development server

```bash
npm run dev
```

The application will be available at `http://localhost:5173`.
